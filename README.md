# Campus Bites

Campus Bites is an informational website for a fictional university cafeteria.

## Project Objectives

- Introduce the Campus Bites cafeteria.
- Display food categories and prices.
- Show daily specials and combo deals.
- Explain how to place an order.
- Provide contact information and a feedback form.

## Technologies

- HTML5
- CSS3
- Git
- GitHub

## Project Structure

- `src/index.html`: Home page
- `src/menu.html`: Food menu
- `src/deals.html`: Daily specials and deals
- `src/order.html`: Ordering instructions
- `src/feedback.html`: Feedback and contact information
- `styles/style.css`: Shared stylesheet

## Development Workflow

The team uses Git and GitHub with feature branches, Pull Requests, code reviews, and release management.
